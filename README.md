# 🎮 Emotion Engine - GameLearn

Plataforma de Aprendizaje Basado en Juegos desarrollada para **Hackathon Nicaragua 2026**.

## 🚀 Descripción General
Emotion Engine es una solución educativa gamificada diseñada para transformar la experiencia de aprendizaje mediante la resolución de trivias, acumulación de XP, niveles e insignias en tiempo real.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
* **Control de Versiones:** Git & GitHub
* **Base de Datos:** Modelo Entidad-Relación en 2FN (DBML / SQLite)

## 🔐 Seguridad y Roles Integrados
El sistema cuenta con la definición y simulación de 3 roles principales:
1. **Usuario (Estudiante/Docente):** Acceso al tablero de misiones y avance de niveles.
2. **Administrador:** Creación y gestión de trivias/misiones.
3. **Auditor:** Verificación del control de calidad e historial de puntos asignados.

## 💻 Instrucciones de Ejecución Local
1. Clonar o descargar este repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox).
